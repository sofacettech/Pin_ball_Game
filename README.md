# So/Facet Pinball

## Run locally

1. Install Node.js 22 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.

## Production build

Run `npm run build`. The playable production site is written to `dist/`. To preview it locally, run `npm run preview`.

The `src/` and `public/` folders are required. Keep `public/assets/` and `public/references/` in place; the game loads them at runtime.
